{{- /* layouts/partials/sort-pinned.html Input: a page list, newest first (e.g. $pages.ByPublishDate.Reverse). Returns a slice in homepage order: 1-2. pinned items with an upcoming event_date, soonest event first 3. other pinned items (no event_date, or the event has passed), newest first 4. everything else, newest first Pinned = pin_until is set and still in the future (same test as before).
