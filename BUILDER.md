# A members page that will create an Article template on demand

Proposal:  a form that has all the metadata fields/taxonomies we just discusses.

1. Can we have a "private" (insofar as there's a page, just not in search, or listed anywhere - there might be better ways to DO this, but that would suffice) page...

2. ... that has a form with the Article metadata pieces
   * And other pertinent questions (will this page have images/video, share on FB, etc.)

3. ... which when filled out creates a Markdown template index.md file with Lorem Ipsum content

THAT way a user can do this, and then just copy/paste the Markdown into an index.md file "fill in the blanks" with content.

## Benefits:

1. Lower chance of user error
   * I mistakenly had tabs in my metadata, and crashed the site.
2. Lower burden on the user for writing articles - most of the "tech" parts are filled out
3. Easier to bring new page features to the user (just add the options for the form)
