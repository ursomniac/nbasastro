## ❌ THE BROKEN PIECE: ALMANAC WIDGET
The `layouts/partials/almanac-widget.html` is currently failing.
* **The Goal:** Real-time Sunrise, Sunset, Moonrise, and Astronomical Twilight for North Adams, MA (42.70, -73.11).
* **The Conflict:** Open-Meteo splits these variables across two different endpoints.
    *   **ENDPOINT A (`/v1/forecast`):** Contains `sunrise`, `sunset`, and `astronomical_twilight_end`.
    *   **ENDPOINT B (`/v1/astronomy`):** Contains `moonrise`.
* **Current Error:** 400/404 errors due to malformed URLs and parameter mismatch. **MUST** use two separate `fetch()` calls or a parallel `Promise.all()`.
* **Data Format:** Open-Meteo returns values as **arrays** (e.g., `sunrise: ["2026-04-18T06:05"]`). Logic must access index `[0]` before splitting.
