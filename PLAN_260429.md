### 1.1. Astro Explorer section listing page

PROBLEM: there are 14 pages one for each taxonomy.
However, the ordering of objects within are done "alphabetically" which is
wrong for some of them.

PROBLEM: some have a set number of potenial entries, others are more "expansive".
The second group should be paginated.

PROBLEM: the default rendering puts all the items in cards reflecting the article_card.html
which is inappropriate for these.   They should be in tables, ordered correctly.

ALPHABETICAL* - these can start out alphabetically, but might need a more custom
format later on.

ISSUE: DO NOT CHANGE the layouts/_default/taxonomy.html file!  Every attempt doing
this broke the Series and Tags pages.

NUMERIC: THIS HAS TO FOLLOW 1, 2, 3..., 9, 10, 11... ordering, not 1, 10, 100, 101...

CUSTOM: Asteroids have a number and a name, OR a designation like "C/2026 AE9",
numbers MIGHT be in parentheses or not.  Numerics should come first in numerical 
order THEN the other ones, alphabetically.  Comets have a similar setup, but for NOW
they can be alphabetical.

It is VERY IMPORTANT that we be able to adjust each taxonomy page as needed later on.
Lumping things might be dangerous.
