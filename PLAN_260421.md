## 3. V0.14 CORE BENCHMARK: THE DARK SECTOR (INTERNAL TOOLS)
The goal is to create a "Member-Only" directory that is invisible to the public, search engines, and internal site search.

### A. EXCLUSION PROTOCOLS
*   **[ ] Directory Lockdown:** Initialize `content/members/` with zero internal links in `nav.html`.
*   **[ ] Archetype Automation:** Implement `archetypes/members.md` with:
    *   `_build: list: never` (Prevents appearing in "Recent" lists)
    *   `sitemap: disable: true` (Removes from sitemap.xml)
*   **[ ] SEO Suppression:** 
    *   Update `static/robots.txt` with `Disallow: /members/`.
    *   Hard-code `<meta name="robots" content="noindex, nofollow">` into the members layout.
*   **[ ] Search Exclusion:** Apply `data-pagefind-ignore` to the `/members` layout to strip documentation from the local search index.

### B. INTERNAL DOCUMENTATION DEPLOYMENT
