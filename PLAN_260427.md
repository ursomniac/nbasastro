## 4. Article Builder
The ideal thing would be to have a Javascript script on a page with a 
very dynamic form.   Filling out the form would produce an index.md 
file that the user can copy/paste to use for a new article.

It would try to navigate all the complex metadata
1. Metadata
    1. Simple metadata (required)
        - title: "My title"
        - date: "2026-05-01"
        - authors: ["My Name"]
        - byline: "some interesting phrase"
    2. Optional metadata
        - series: []
        - tags: []
    3. Sectional metadata
        - solarsystem: []   (make a checkbox list)
        - catalogs: []      (make a checkbox list)
        - stargroups: []    (make a checkbox list)
    4. Sectional specifics:  for each section with entries, create the indented
       lines for that:
        - stardata: 
        - object_sections:

    2. Images (put in the 4 general types)
    3. Galleries (put in the 2 options)
