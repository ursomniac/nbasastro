# Resizing Images — Windows

Two methods: Photos app (built in, no installation) or IrfanView (free,
faster for multiple files).

---

## Method 1: Photos App

The Photos app is built into Windows — no installation needed.

1. Open the image in **Photos**
2. Click the **three-dot menu** (top right) and choose **Resize**
3. Select **Define custom dimensions**
4. Set **Width** to `2000` pixels (or less)
5. Make sure **Maintain aspect ratio** is checked
6. Click **Save resized copy**

> Photos saves a copy — your original is preserved. Replace the original
> in your article directory with the resized copy.

For multiple images, Photos does not support batch resizing. Use IrfanView
instead.

---

## Method 2: IrfanView (Recommended for multiple files)

IrfanView is a free image viewer with powerful batch processing.
Download it from [irfanview.com](https://www.irfanview.com).

**Single image:**

1. Open the image in IrfanView
2. Go to **Image → Resize/Resample**
3. Set **Width** to `2000` pixels
4. Make sure **Preserve aspect ratio** is checked
5. Click **OK**
6. Go to **File → Save** to overwrite the original

**Multiple images (batch):**

1. Go to **File → Batch Conversion/Rename**
2. Add all the image files you want to resize
3. Check **Use advanced options**
4. Click **Advanced** and set **Resize** to `2000` pixels wide
5. Set the output folder to your article directory
6. Click **Start Batch**

---

## Checking File Size

In File Explorer, select your image files, right-click and choose
**Properties**. The size is shown on the General tab.

Aim for under 2MB per image.
