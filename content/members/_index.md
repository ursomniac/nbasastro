## How to Contribute an Article

Members can contribute articles at any level of technical comfort.
Choose the pathway that fits your setup:

<div class="article-body">

| Pathway | What you need | How you submit |
|---|---|---|
| [Pathway 1 — Full Git](/members/pathways/pathway-1/) | Git + Hugo installed locally | Pull request on GitHub |
| [Pathway 2 — Local Preview](/members/pathways/pathway-2/) | Hugo installed locally | ZIP file by email |
| [Pathway 3 — No Setup](/members/pathways/pathway-3/) | Nothing | ZIP file by email |
| [Pathway 4 — CMS](/members/pathways/pathway-4/) | A web browser | Via the CMS interface |

</div>
