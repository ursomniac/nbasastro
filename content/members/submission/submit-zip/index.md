# Submit by ZIP

Used by Pathway 2 (local preview) and Pathway 3 (no setup).
ZIP your article directory and email it to the site administrator for review.

---

## What to ZIP

ZIP the entire article directory — not just the files inside it.
The directory should contain:

- `index.md` — your article file
- All image files used in the article

**Do not include** any files outside your article directory.

---

## Creating the ZIP

**On Mac (Finder):**

1. Locate your article directory in Finder
2. Right-click the directory
3. Choose **Compress "your-article-name"**
4. A file called `your-article-name.zip` is created alongside the directory

**On Mac (Terminal):**

{{< highlight bash >}}
cd ~/Documents/Projects/NBAS/content/articles/2026/05
zip -r my-article-name.zip my-article-name/
{{< /highlight >}}

**On Windows (File Explorer):**

1. Locate your article directory in File Explorer
2. Right-click the directory
3. Choose **Send to → Compressed (zipped) folder**
4. A `.zip` file is created alongside the directory

---

## Sending the ZIP

Email the ZIP file to the site administrator:

- **To:** [site administrator email]
- **Subject:** `Article submission: [your article title]`
- **Attach:** your ZIP file

Include a brief note if there is anything the administrator needs to know
about the article — scheduled date, series it belongs to, etc.
